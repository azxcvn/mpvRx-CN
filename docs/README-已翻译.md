## 功能特性

mpvRx 通过深度自定义、温控感知性能和独特的易用性特性，进一步提升了 mpv-android 的体验。以下是它的独特之处：

<details close>
<summary><b>🎨 主题与视觉系统</b></summary>

| 功能 | 说明 |
|---|---|
| **25+ 种色彩主题** | 默认、动态取色 (Material You)、Catppuccin、Nord、Tokyo Night、Rose Pine、Gruvbox、Dracula 等多种主题 |
| **AMOLED 纯黑模式** | 每个主题均提供采用纯黑背景的专属变体 |
| **播放器控件动画** | 5 种动画风格：默认、弹性回弹 (Elastic Bounce)、影院缩放 (Cinematic Scale)、向上滑动 (Slide Up)、极简淡入淡出 (Minimal Fade) |
| **始终深色模式** | 无论应用全局主题为何，均可设置播放控件始终保持深色主题 |
| **主题化播放控件** | 自适应控件设计，自动匹配应用主题或系统强调色 |
| **Material 3 表现力界面 (Expressive UI)** | 表现力组件、弹性导航动效、响应式网格以及精致的预测性返回手势动效 |

</details>

<details close>
<summary><b>🖐️ 手势系统</b></summary>

| 功能 | 说明 |
|---|---|
| **精细的双击逻辑** | 可配置的双击跳转区域（左/中/右），支持独立分配操作 |
| **多击连续快进/快退** | 三击/四击无需抬手即可持续进行跨度更大的快进/快退 |
| **水平滑动跳转** | 在视频画面上滑动即可调节播放进度，并带有实时时间与增量浮层 |
| **长按动态倍速** | 长按激活可配置的加速播放；左右滑动可在 8 个预设倍速档位之间自由微调 |
| **字幕拖动手势** | 字幕显示状态下，长按屏幕中央可垂直拖动调整字幕位置 |
| **字幕缩放与台词跳转** | 双指捏合缩放调整字幕大小，在字幕上滑动可在前后台词句之间快速跳转 |
| **双指缩放与平移** | 双指缩放视频（-1x 至 3x），支持缩放时同步平移以及缩放后单指平移拖动 |
| **手势音量增益** | 垂直滑动调节音量可突破 100%，进入可配置的音量增益 (Boost) 范围 |
| **左右侧调节互换** | 支持互换屏幕左侧与右侧分别控制音量或亮度的逻辑 |

</details>

<details close>
<summary><b>📺 HDR 与视频管线</b></summary>

| 功能 | 说明 |
|---|---|
| **基于着色器的 HDR 管线** | 由 [hdr-toys](https://github.com/natural-harmonia-gropius/hdr-toys) 驱动 —— 内置 77 个 GLSL 着色器 |
| **四种 HDR 模式** | BT.2100 PQ (HDR10)、BT.2100 HLG、BT.2020 色域映射、Linear HDR |
| **SDR 转 HDR 增强** | 使用 Linear HDR 管线时，可将普通 SDR 内容的动态范围智能扩展至 HDR |
| **GPU 去色带 (Deband)** | 支持 CPU (gradfun) 或 GPU 去色带，具备可配置的迭代次数、阈值、范围与噪点控制 |
| **智能渲染后端** | 根据设备支持情况，自动在 OpenGL/Vulkan 以及 gpu/gpu-next 之间智能匹配最佳方案 |

</details>

<details close>
<summary><b>🔥 温控与电池管理</b></summary>

| 功能 | 说明 |
|---|---|
| **ThermalMonitor** | 播放期间每 10 秒采样一次系统温控余量 (thermal headroom) |
| **自适应着色器开销** | 根据温控状态自动限制环境光着色器的计算负荷 |
| **Anime4K 主动降级** | 当温控余量降至 40% 以下时，自动调低 Anime4K 画质档位防止过热 |
| **后台轮询优化** | 当控件隐藏时，播放进度轮询间隔翻倍，削减 50% 的 JNI 唤醒开销 |
| **统计轮询退避** | 播放暂停时，统计信息页的轮询循环由 1 秒退避至 2 秒 |

</details>

<details close>
<summary><b>🧩 Anime4K 与超分辨率</b></summary>

| 功能 | 说明 |
|---|---|
| **7 档预设画质** | 关闭、A、B、C、A+、B+、C+，支持平滑无缝切换 |
| **解码器设置中的画质档位** | 提供 快速 / 均衡 / 高画质 预设选项 |
| **4K/8K 安全防护** | 对超高清分辨率内容自动禁用 Anime4K，防止超载崩溃 |
| **温控防护选择** | 面临高温散热压力时，在发生掉帧之前自动降低画质档位 |

</details>

<details close>
<summary><b>💡 环境光模式 (Ambient Mode)</b></summary>

| 功能 | 说明 |
|---|---|
| **两种视觉模式** | 柔光 (GLOW) 与 画面延伸 (FRAME_EXTEND) —— 均在运行时通过自定义 GLSL 渲染 |
| **15+ 项可配置参数** | 模糊采样数、光晕强度、饱和度、暖色调、暗角、抖动噪点等细节调节 |
| **着色器重编译缓存** | 当参数与上次编译版本匹配时自动跳过重新编译，节省性能 |

</details>

<details close>
<summary><b>📝 字幕系统</b></summary>

| 功能 | 说明 |
|---|---|
| **双字幕支持** | 主字幕 + 副字幕同屏展示，并支持自动偏移以避免画面重叠遮挡 |
| **ASS 覆盖模式** | 副字幕的智能强制与缩放覆盖机制 |
| **全方位样式定制** | 字体、字号、粗体、斜体、边框、阴影、颜色、对齐方式、随窗口缩放 |
| **三种在线搜索模式** | Wyzie、SubtitleHub（聚合 6 个来源）以及混合模式（合并二者结果） |
| **TMDB 集成** | 完整的影视媒体元数据搜索，支持按季/集精确检索字幕 |
| **字幕字体管理器** | 自定义字体目录、重新加载字体、清空缓存并指定默认字幕字体 |
| **语音转字幕生成** | 实验性功能，可利用支持的云端或离线 Whisper 模型直接根据音轨生成字幕 |
| **直接关闭字幕** | 支持一键关闭字幕，无需逐一轮转切换所有轨道 |

</details>

| **自定义用户按钮** | 创建执行任意 Lua、JavaScript 或 mpv 内置命令的专属按钮 |
| **横竖屏自适应布局** | 针对横屏与竖屏方向分别保存完全独立的操作界面布局 |
| **“滑动解锁”控制** | 控件锁定状态下通过滑动滑块实现解锁，防止误触 |
| **隐藏按钮背景** | 提供纯透明按钮样式，仅保留图标显示 |
| **集中式“更多”面板** | 快速调出所有播放器按钮和自定义控制项目 |
| **播放中即时设置** | 无需离开播放界面即可实时调整 10+ 项设置（手势、画中画、界面交互等） |

</details>

## 🔋 Mpv 电池与续航优化指南

新手的第一条核心建议：**如果不熟悉，请保持 Mpv Conf 配置文件为空**

- **请使用 `gpu` 而不是 `gpu-next`** —— gpu-next 是基于 Vulkan 的现代渲染器，在播放普通视频时可能会让 GPU 始终处于高频运行状态。而经典的 `gpu` 后端更为轻量，采用 OpenGL 驱动栈，在绝大多数 Android 设备上具有更优越的能耗表现。
- **完全禁用 Vulkan。** Vulkan 在视频渲染方面确实出色，但能耗负担也相对较重。
- **使用 `fast` mpv 预设配置。** 该配置已内置于 mpvRx 中，可直接在 Mpv 配置中将其选为默认，或在 _mpv.conf_ 中添加 `profile=fast`。
- **不要滥用着色器 (Shaders)。** 你所开启的 Anime4K 等预设着色器正是电量飞速消耗的元凶。着色器在每一帧画面上都需要经过 GPU 计算。如果你在观看 24fps 的视频并挂载了着色器管线，这意味着每秒要做 24 次不必要的 GPU 密集运算，而在手机这样的小屏幕上能换来的画质提升微乎其微。
- **不要盲目套用 AI 生成的配置。** 说的就是那些直接从 Reddit 复制粘贴包含 200 行 `scale=ewa_lanczossharp`、`dscale=mitchell`、`cscale=sinc` 和一堆 `glsl-shaders` 语句的用户。大多数人根本不清楚这些参数的实际含义，只是一味让手机以渲染 4K 影院巨幕投影的标准去运算视频。在一块 6 英寸的手机屏幕上，请保持理智 —— 这是你的 Android 手机，不是价值数十万的 4K 专业影院电视。

**个人观点：** mpv 使用默认配置搭配 `profile=fast` 以及 `gpu` 渲染后端时，对电池的消耗其实非常低 —— 甚至往往比手机厂商自带的原生播放器**更省电**，因为 mpv 没有后台常驻的各类专有 DRM 模块、数据统计分析 SDK 以及广告框架去空耗 CPU。下一次如果发现看一部 2 小时的电影掉电超过 20-25%，不要急着怪罪 mpv，先检查一下自己是不是盲目套用了十几个着色器脚本。

_实用的经验法则：如果你的电池消耗能保持在 200 mAh 以内且功耗低于 0.9W（可查看 mpvRx 视频播放器“更多设置 -> 统计信息第 6 页”），那么你的 Mpv Conf 配置就处于适宜观看视频的合理范围。这是经过实际测试总结的经验，至于更深层次的技术细节请自行探讨，无需额外争论。_

| 密钥名称 | 说明 |
|---|---|
| `SIGNING_KEYSTORE` | Base64 编码的签名密钥库文件 (`.jks` 或 `.keystore`) |

git tag -a v1.3.1 -m "Release version 1.3.1"
git push origin v1.3.1

预览版本的发布流程相同，使用如下格式的预览标签即可：
