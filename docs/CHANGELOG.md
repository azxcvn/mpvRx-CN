# 更新日志

以下内容以通俗易懂的方式记录了各版本的实际变化。

## 2.0.0 — 正式版

### 🎵 音乐播放器与音频体验
- **专属音乐/音频播放器界面**：全新完整的音频播放器 UI，支持竖屏/横屏自适应布局、动态主题背景、透明可视化、封面美化与实时元数据显示
- **平板横屏双窗格音乐播放器**：针对平板优化的双窗格音乐播放器布局，支持流畅的拖拽播放列表排序
- **交互式音频可视化器**：
  - **3D 立方体隧道可视化器**：移植原生 Compose Canvas 3D 隧道可视化器，支持动态隧道半径、触摸操控、3D 旋转手势、双指缩放、全屏缩放、动态主题配色与交互响应
  - **OpenGL Blob 与银河可视化器**：高频率频谱采集、FFT 音频能量处理、调谐频率包络、帧时感知插值，以及响应式节拍衰减，渲染流畅无跳帧
  - **PCM 可视化管线**：新增逐频段 FFT 纹理管线，支持双波形/FFT 采集，增强音频频谱分析
- **独立的后台播放控制**：为音频和视频媒体引入独立的后台播放设置，含通知权限提示、系统亮度有效范围限制与自动服务清理
- **更智能的媒体通知**：音频通知现在会去除曲目标题中的文件扩展名，当 MPV 未报告缩略图时回退到内嵌专辑封面
- **不间断后台音乐**：播放音频时滑动返回不会中断歌曲，从通知重新打开播放器时播放服务保持存活，关闭后台播放设置时不再暂停正在播放的音乐
- **均衡器与音频滤镜**：内置均衡器，MPV 音频滤镜更新带防抖处理，滑块移动顺滑，支持 A-B 循环与持久的音调修正控制
- **音频播放列表管理**：新增播放列表项拖拽排序、M3U/IPTV `tvg-logo` 缩略图回退、正方形 1:1 封面卡片，以及同级音频文件自动列表填充
- **音频播放器方向与控件**：新增可配置的音频播放器方向设置、竖屏模式居中播放/暂停控件、专属音频后台播放开关
- **音频模式 UI 修复**：音频模式下打开面板时系统栏不再闪烁，进度条计时器颜色随主题自适应

### 📺 Google Cast 与远程控制
- **原生 Cast 集成**：在竖屏和横屏播放器控制栏均添加有状态的 Google Cast 按钮，支持现有配置的布局迁移
- **本地与远程媒体交接**：远程 HTTP(S) 流直接投屏；本地 `file://` 与 `content://` 媒体通过安全的带令牌本地 HTTP 服务器提供，支持字节范围拖动与 CORS
- **远程投屏控制器**：功能完整的远程控制对话框，支持播放/暂停、音量调节、进度拖动、播放速度选择与媒体轨切换
- **播放连续性**：在本地设备与投屏接收端之间转移播放时同步标题、播放状态、时长与位置，断开连接时恢复状态
- **优雅降级**：设备不支持 Google Cast 模块时播放器仍保持完整可用

### ⚡ 性能与视频播放器优化
- **GPU 视图变换**：实现硬件加速的 GPU 视图变换，视频平移和缩放极致流畅
- **精炼触控手势**：视频平移手势限定为双指操作，防止快进或调节音量/亮度时误触屏幕位移；视频与字幕手势开关解耦
- **吸附式预设长按速度**：长按加速手势吸附到固定预设（0.5x、1x、1.5x、2x、2.5x、3x、3.5x、4x），以清晰的文字药丸显示，取代旧版悬浮滑块
- **原生缩略图管线**：集成快速原生视频缩略图提取管线（移植自 mpvRex），进度条拖动即时预览，可见缩略图自动刷新
- **YouTube 风格环境光**：新增环境背景模式，动态投射与视频画面匹配的色彩高光
- **显示刷新率自动匹配**：自动调整显示刷新率以匹配视频源帧率，画面流畅无撕裂
- **Anime4K 与 Vulkan 超分**：新增独立 Anime4K Ultra 超分模式，带 `gpu-next` Vulkan 需求检查与优化的基准配置
- **HDR 模式强化**：HDR 模式现在由渲染器支持（GPU Next + Vulkan）正确门控，禁用 HDR 时色彩恢复正确，并记住上次选择的 HDR 模式
- **线性 HDR 恢复**：恢复线性 HDR 使用 mpv 原生管线（不使用 hdr-toys 着色器），修复支持设备上的亮度问题
- **稳健的播放会话**：新增 mpv 会话协调器，可靠地销毁并恢复会话（崩溃后无幽灵播放器），净化 mpv 配置并收集播放器诊断信息
- **负亮度控制**：支持负亮度调节，可将屏幕调暗至系统默认最低值以下
- **快速启动与即时播放**：文件加载转移到 `Dispatchers.Default`，消除 UI 线程阻塞；延迟冷启动数据库初始化、语法预加载和自动更新检查，显著缩短首帧时间
- **截图时间戳与模板**：重做截图模板（`%F`、`%P`、`%p`、`%wH`、`%wM`、`%wS`、`%wT`），使用精确的视频播放位置而非系统时钟
- **音频解码回退**：压缩器中新增音频解码器检查与不支持音频编解码器的回退处理

### 📱 界面与现代平板双窗格设计
- **Telegram 风格悬浮药丸导航栏**：重新设计的底部导航栏，采用现代悬浮药丸设计、平滑滑动指示器动画，以及跟随手指滑动的药丸联动效果

## 1.5.0-preview.2 — 预览版

### 📦 MpvLib 更新
- 更新了 mpv 库及其依赖项

### ⚡ 性能与启动优化
- **更快打开视频**：打开视频文件时使用 `Dispatchers.Default` 调用 `playFile()`，避免阻塞 UI 线程，播放器启动更快
- **更轻量的启动同步**：MPV 目录同步不再每次启动时全量复制 `shaders/` 和 `fonts/`，仅预先同步配置文件、脚本和 `script-opts/`。`mpv.conf` 中引用的着色器通过 `syncReferencedShaders()` 按需拉取，字体由字体管理器处理。对于着色器包较大的用户，启动时间明显缩短
- **移除动态速度叠加层**：旧的 `SpeedControlSlider`（全屏圆点轨道滑块）和 `CompactSpeedIndicator` 已移除。长按加速现在显示为简洁的文字标签（如 "2x"），`showDynamicSpeedOverlay` 偏好设置也已移除
- **长按速度吸附预设值**：长按加速手势现在吸附到固定预设值（0.5x → 1x → 1.5x → 2x → 2.5x → 3x → 3.5x → 4x），不再是自由滑动。设置中的滑块也会吸附到这些值
- **加速范围上限调整**：加速速度上限从 6x 调整为 4x（范围 0.5x–4x）

### 📱 平板双窗格布局
- **文件夹双窗格视图**：在平板设备上（最小屏幕宽度 ≥ 600dp），可在左侧查看文件夹列表，右侧查看视频列表。点击文件夹即可在右侧看到其内容。外观设置中新增"双窗格视图"开关
- **设置双窗格视图**：设置界面在平板上也采用双面板布局，左侧为分类列表，右侧显示对应设置页，当前选中的分类有高亮背景
- **双窗格返回导航**：双窗格模式下按返回键取消选中文件夹/设置页，而非关闭整个界面

### 🎥 播放器与字幕
- **反转字幕滑动方向**：手势偏好中新增"反转字幕滑动方向"设置。启用后从左向右滑动快退，从右向左滑动快进
- **截图文件名模板重做**：
  - `%wH`、`%wM`、`%wS`、`%wT` 现在使用视频播放位置（而非系统时钟），截图文件名与实际视频时间戳一致
  - 新增模板占位符：`%F`（不含扩展名的文件名）、`%P`（位置，格式为 `HH:MM:SS.mmm`）、`%p`（位置，格式为 `HH:MM:SS`）
  - `%f` 优先使用实际文件名，回退到媒体标题，命名更可靠
- **韩文谚文字幕修复**：下载的韩文谚文（组合字符）字幕现在经过 NFC Unicode 规范化处理，不再出现损坏的韩文字符
- **字幕搜索键盘修复**：为 PlayerActivity 添加 `android:windowSoftInputMode="adjustResize"`，字幕搜索对话框不再被虚拟键盘遮挡
- **字幕持久性修复**：外部字幕和字幕设置现在能在播放会话之间更可靠地保留。新增 `addSubtitleSuspend()`（挂起版本）以改善协程处理
- **缓存指示器修复**：进度条上的缓冲范围不再重复计算已播放部分，现在正确显示播放头前方的剩余缓冲
- **颜色十六进制修复**：`toColorHexString()` 现在手动提取 ARGB 分量，解决了某些颜色使用 `Int.toHexString()` 产生错误值的问题

### 🛠️ Lua 脚本改进
- **Lua `require()` 支持**：使用 `require()` 的自定义 Lua 脚本现在可以在 `script-modules/` 子目录中找到模块。应用会递归地将 `scripts/` 中的辅助文件夹同步到内部存储，以便 Lua 的 C 级 `fopen()` 能够读取。在设置中禁用脚本时，模块也会被清理

### 🧹 清理
- **移除 libpython 二进制文件**：从所有 4 个架构中删除了约 50 MB 未使用的 `libpython_bin.so` 文件
- **简化 MPV 版本显示**：移除了 CrashActivity 中的 `cleanBundledMpvVersion()` 方法，MPV 版本现在直接显示，无需字符串修补
- **字体文件夹不再自动设置**：更改基础存储根目录时，字体文件夹偏好设置不再被盲目覆盖，仅当指向旧根目录时才清除，防止意外重置
