# mpvRx 安装包版本与架构选择指南

为了保证播放器在不同设备上发挥出最佳的解码性能与能效比，mpvRx 提供了针对不同 CPU 芯片架构独立编译的安装包（APK）。

如果您在下载页面看到多个不同名称的 APK 文件，不知道该选择哪一个，请参考本文档。

---

## 快速选择结论（极简推荐）

- **目前绝大多数 Android 手机和平板**：下载 **64 位（arm64-v8a）** 版本（性能最佳、体积适中）。
- **完全不知道设备架构，或者安装其他版本报错**：下载 **通用不分包（universal）** 版本（体积较大，但 100% 兼容所有设备）。
- **电脑上的 Android 模拟器**：优先下载 **X86-64（x86_64）** 版本，或使用 arm64-v8a 版本。
- **老旧手机、旧款电视盒子或车机**：下载 **32 位（armeabi-v7a）** 版本。

---

## 5 个安装包版本详细解析

| 安装包标识 / 名称 | 架构类型 | 推荐使用设备 | 特点与说明 |
| --- | --- | --- | --- |
| **arm64-v8a** (arm64 / aarch64 / 64位) | 64 位 ARM 架构 | 2016 年以后生产的绝大多数 Android 手机与平板（高通骁龙、联发科天玑、华为麒麟、三星 Exynos 等） | **最推荐的首选版本**。纯 64 位执行，运行效率最高，视频软硬解码速度最快，体积合适。 |
| **armeabi-v7a** (arm-v7a / v7a / 32位) | 32 位 ARM 架构 | 早期老旧手机/平板、部分低配网络电视盒子、老旧车机系统 | 针对 32 位处理器的兼容版本。若设备不支持 64 位应用，只能安装此版本。现代设备也能兼容运行，但性能略低。 |
| **universal** (不分包 / 全架构版本) | 包含所有架构（全兼容） | 任何无法确认芯片架构的设备，或单架构包安装提示不兼容时 | 内置了 arm64、armv7a、x86、x86_64 所有的库文件。**兼容性最好，绝不会报错**，但文件体积约为单架构包的 2~3 倍。 |
| **x86_64** (x86-64) | 64 位 x86/PC 架构 | PC 电脑上的 64 位 Android 模拟器（MuMu、雷电、逍遥等）、搭载 Intel/AMD 芯片的 Android 平板、ChromeOS | 针对 x86 电脑处理器原生编译。在模拟器中运行无需经过 ARM 指令集转译，CPU 占用最低，画面最流畅。 |
| **x86** | 32 位 x86 架构 | 早期的 32 位 PC Android 模拟器、早期搭载 Intel Atom（阿童木）芯片的平板 | 目前较为罕见。除非您的模拟器或设备明确为 32 位 x86 系统，否则通常不需要下载此版本。 |

## 常见问题与排查方法

### 1. 安装时提示“解析软件包时出现问题”或“应用未安装 / 与设备不兼容”？
- 原因通常是下载了与当前设备 CPU 架构不匹配的文件（例如将 `x86_64` 安装到了 ARM 架构手机上，或将 `arm64-v8a` 安装到了 32 位旧盒子上）。
- **解决方法**：直接下载 **universal（通用不分包版本）** 重新安装即可解决。

### 2. 如何查看自己手机/设备的具体架构？
- 可以在应用商店下载系统信息检测工具（如 **AIDA64** 或 **DevCheck**），在“处理器 (Processor)”或“系统 (System)”一栏查看 CPU 指令集类型。
- 如果支持 `arm64-v8a` / `aarch64`，直接选择 64 位包即可。
