# 更新日志 (Changelog)

这些说明用通俗易懂的语言编写，重点关注实际使用中的变化。

## 2.5.0 - 逐帧回放、自动裁切与媒体库性能优化

> [!IMPORTANT]
> **项目暂停公告：** 在 2.5.0 版本发布后，mpvRx 的开发将暂停，直至另行通知。

### 🎬 逐帧回放、跳转与播放
- **帧级回放 (Frame-Level Review)**：新增全屏播放器逐帧回放模式，支持水平滑动切帧、上一帧/下一帧控制、精确到帧和毫秒的数值读取、带可选字幕的截图快照，以及透明自适应布局。
- **按帧定位时间轴**：逐帧回放滑块现可选择整数视频帧。拖动时使用节流的关键帧预览，松手时执行精确的 mpv seek 跳转，并带有边界精细微调和邻帧校正，确保精度的同时不会持续加重解码器负载。
- **可靠的前进与后退跳转**：后退跳转使用精确目标位置以保持音视频同步。前进跳转会在文件结尾 (EOF) 前安全停止，随后的前进操作可顺利完成播放，而不会在接近片尾时失去响应。
- **更安全的渲染表面恢复**：在 Android 播放 Surface 销毁之前暂停 MediaCodec 视频，且仅在匹配的播放代次 (generation) 恢复，减少表面重建后的黑屏和解码器崩溃问题。
- **移除 thumbfast 跳转预览**：移除了独立的 ThumbFast 浮层引擎、帧解码缓存、偏好设置和 UI。进度拖动现统一采用受节流控制的实时视频预览方案，减少重复解码开销并避免预览竞争。
- **更平滑的启动与控制栏**：减少了启动时控件闪烁，用可预测的定时过渡取代了过冲弹性动效，并改进了跳转合并机制，使快速手势能稳定停在最后请求的位置。
- **首帧即可确定正确方向**：本地视频在进入播放器前即可传递已知尺寸，从而在画面渲染前就能正确选择横屏或竖屏方向，避免启动后发生画面旋转。
- **跨过渡状态保持正确音频状态**：播放退出清理逻辑不再将临时的跳转静音带入下一个文件，并且在文件到达 EOF 时立即持久化终止播放状态。
- **持久化视频几何布局**：视频缩放状态在文件切换后依然保留，裁切、平移、缩放、拉伸和环境光渲染现已共享统一且一致的几何路径。
- **运行时修改即时生效**：清空播放历史会立即更新底层仓库状态，编辑后启用的 Lua 脚本会在播放核心下次初始化时直接生效。

### ✂️ 自动裁切与视频输出
- **自动黑边裁切**：新增 Auto Crop 画面比例模式，通过对多帧采样、谨慎检测固定的黑边，并缓存测量结果以供重复播放使用。
- **动态画幅安全保障**：自动裁切现可安全处理多变画幅比、源视频旋转以及短小或昏暗场景，不会残留过期的裁切尺寸。
- **兼容拉伸与环境光**：裁切在拉伸布局下依然正常工作，并基于相同的最终视频几何尺寸同步更新环境光背景。
- **全面本地化的自动裁切体验**：自动裁切的状态、操作、结果和错误提示已完整适配所有支持的应用语言。
- **更纯净的 HDR 配置**：移除了冗余的色调映射与色域映射覆盖项，使 HDR 输出直接遵循所选管线，避免转换冲突。

### 🎛️ 播放器控件、画中画与导航
- **欢迎引导不再阻断应用**：“开始使用”现在始终可以进入应用主界面，即使跳过了权限授予 —— 引导完成页面会在琥珀色警告中列出所有缺失的权限（取代之前的快速导览开关），需要存储权限的界面则会展示紧凑的“授予访问权限”就地提示。
- **搜索栏适配状态栏与挖孔**：内置搜索栏（文件夹、视频、音乐、播放列表、网络、Jellyfin）不再被状态栏和前置摄像头挖孔遮挡 —— Material 搜索迁移中丢失的系统内边距现已恢复。
- **流媒体链接接管开关**：播放器设置中新增“打开流媒体网站链接”开关，用于控制 mpvRx 是否注册接管 YouTube、Vimeo、Twitch、Odysee 和 Bilibili 链接 —— 关闭后此类链接将直接调用对应客户端打开，而直接媒体 URL 依然保持生效。
- **播放列表首项显示修复**：从文件夹中打开非首个视频时，播放列表弹层的第一行不再错误显示当前打开视频的名称 —— 临时单项队列中的过期元数据会在文件夹播放列表发布前被正确清除。
- **右侧边缘操作面板**：新增右侧边缘拉手，可在可拖动面板 (`DraggablePanel`) 中展开播放器的全部操作快捷项。
- **一致的操作磁贴**：播放操作采用响应式三列磁贴布局，图标大小标准化，无嵌套圆形背景，采用动态色彩，并为后台播放、HDR、环境光、循环、随机、画面变换、倍速和缩放等激活设置提供全磁贴激活指示。
- **长按倍速锁定**：新增滑动锁定长按倍速手势，带有触觉反馈，在释放锁定时能可靠恢复至 1x 倍速。
- **可配置音频跳转时长**：音乐播放器的快退和快进控件现在遵循配置的双击跳转时长。
- **可靠的画中画 (PiP) 交接**：放大画中画可在不中断播放的情况下恢复全屏播放器，返回键在适当时打开迷你播放器，画中画关闭操作能够干净利落地停止播放。
- **支持链接路由扩展**：扩展了对支持的 YouTube 域名的默认打开覆盖范围。

### 🌐 网络流媒体与协议
- **恢复片尾自动播放下一项**：视频和音乐在播放结束时可再次自动播放队列中的下一项 —— 无论在播放器内还是在后台播放期间。此前 2.5.0 的修改抑制了 keep-open 构建所依赖的 EOF 信号；现在该信号恢复正常并会根据播放位置进行校验，防止网络连接中断误判为播放结束。
- **代理连接槽泄漏修复**：超时的网络代理操作不再让迟到的上游数据流保持打开，避免耗尽小型服务器的连接上限导致后续请求全部失败。
- **WebDAV 播放可靠性**：对于在根目录拒绝或返回空深度 0 PROPFIND 的服务器（在反向代理后很常见），播放不再直接失败 —— 现在仅在凭证被拒时中止连接，且当 PROPFIND 无法提供大小时降级使用 HTTP HEAD/分段探测获取。失败的代理流也会恢复：无效的上游会话会被驱逐以便下次 seek 重新连接而不是永久缓冲，并且上游失败现在会记录日志（已脱敏）而非静默返回 503。
- **本地代理流排除 yt-dlp**：环回代理 URL（所有 SMB/FTP/SFTP/WebDAV/种子流播放）被明确排除在 yt-dlp hook 之外，避免无扩展名的网络文件被误转给提取器处理。
- **32 位与 x86 设备上的 YouTube 修复**：修复了在 armeabi-v7a 和 x86 设备上打开 YouTube 分享链接报错“无法加载此链接”的问题 —— 内置 Python 运行时此前仅打包了 arm64 配置，导致 yt-dlp 在提取前抛出 `No module named _sysconfigdata__android_...` 崩溃。
- **SFTP 协议支持**：新增 SFTP 作为全功能网络协议（与 SMB、FTP、WebDAV 并列）—— 支持浏览文件夹、通过安全环回代理进行支持跳转的串流播放，并在统一的添加/编辑弹窗中管理连接（默认端口 22）。
- **大文件卡死与片尾 Seek 修复**：网络重连选项现已作用于主播放流，网络连接中断或 seek 重新打开失败时可自动恢复，避免大文件卡住或在文件末尾向后 seek 时陷入无限缓冲。
- **代理挂起防护**：提前终止的网络响应体现在会作为可恢复的中断呈现，而不会使播放器无限期等待缺失字节。
- **更稳健的 WebDAV 串流**：整文件串流复用共享的 HTTP 客户端（保持超时一致，避免每次请求泄漏客户端），对于忽略分段请求的服务器降级使用 skip-to-offset 串流，使跳转在所有环境下保持可用。
- **网络共享中的音乐支持**：开启“在浏览器中显示音频”后，WebDAV、SMB、FTP 和 SFTP 浏览器可显示并播放音频文件，包括文件夹队列和音频播放器界面。
- **减少重复网络请求**：防止播放启动期间发生爆发式重复网络请求。

### 🎬 播放与稳定性
- **精准片尾跳转**：避免了在 EOF 处执行非精准跳转导致播放意外中断的问题。
- **环境光面板主题适配**：修复了浅色模式下环境光面板的外观样式。
- **更干净的编译构建**：解决了 Kotlin 与 Material API 警告并更新了依赖库版本。

### 🚀 入门引导与快速导览
- **分步式权限引导**：首次运行权限页面现改为分步向导 —— 每屏一个权限并配有进度指示点，完美适配各种屏幕且不发生裁剪。可选权限（通知、音频）可单独跳过，跳过存储权限则直接跳过整个权限流程。
- **快速导览选项**：最后一步设置提供了快速导览开关；应用内交互导览将在后续版本推出。

### 📋 媒体信息
- **图片详细信息**：JPG、PNG、WebP、GIF、TIFF 等图片现拥有专门的“图片”标签页，展示分辨率、格式、位深、色彩空间、压缩方式和方向 —— 包括在音视频文件中发现的内置封面图片。
- **其他与原始信息标签页**：时间码轨道、节目和未来的 MediaInfo 章节类型移入新增的“其他”标签页中，并附带 MKV 附件名称；在“原始”标签页中可直接查看完整的 MediaInfo 报告文本。
- **全值查看器**：点击任意字段即可打开可滚动、可选择文本的弹出窗口，查看完整内容并支持一键复制，长内容不再因截断而丢失。
- **智能类型概览**：图片显示分辨率、格式、位深和体积；音乐显示时长、声道、采样率和比特率；不再显示如“无视频”等无关占位符。
- **完整的容器元数据**：完整列出 MediaInfo 报告的每个常规字段，并在标题下方和容器卡片中同时展示文件的系统物理路径。

### 🌐 网络、存储与字幕
- **网络文件夹书签**：保存、打开和管理已保存 SMB、FTP、WebDAV 连接中常用的高频文件夹，无需重复输入认证信息。
- **加固 WebDAV 播放**：长时间播放串流不再被全局调用超时切断，保留文件名字符仅编码一次，去除重复服务器条目，反向代理 href 路径解析更安全。
- **网络字幕刷新**：针对 WebDAV 及其他网络媒体正确发现并刷新外部字幕。队列上一首/下一首导航现跟随当前网络条目，而不再复用第一项的缓存路径。
- **可配置隐藏文件夹**：新增控制选项，用于包含 Android MediaStore 通常忽略的点前缀隐藏文件夹和 `.nomedia` 目录。
- **增量式隐藏文件夹扫描**：隐藏文件夹发现现复用索引扫描状态并仅刷新发生变更的根目录，而无需反复遍历整个存储树。
- **Android 10 文件操作**：在 Android 10 上恢复了重命名、移动、删除和存储权限交互，同时在较新 Android 版本上保留分区存储 (Scoped Storage) 逻辑。
- **更纯净的字幕颜色设置**：移除了重复的字幕背景颜色控件，由单一设置项管理渲染数值。

### 🎵 音乐、通知、歌词与播放列表
- **通俗 Hinglish 罗马化注音**：为印度系语言新增了非正式拉丁字母歌词选项，包括逐行混合脚本检测、印地语 schwa 隐落、长元音处理、鼻音化修复以及更干净的旁遮普语撇号。
- **切歌后无过期歌词干扰**：正在加载的歌词、源切换和翻译任务会被及时取消并进行身份校验，避免慢速的前一首歌曲覆盖当前歌曲的歌词。
- **可靠的通知栏收藏**：音乐通知栏中的收藏操作使用与应用内相同的持久标识，即时更新并与播放列表变更保持同步。
- **隔离的通知控制**：媒体通知操作现严格定位到活动播放会话，包含关闭操作，并避免重复或跨会话指令干扰。
- **将播放队列存为播放列表**：当前播放器队列可直接保存为具名播放列表。
- **更快的播放列表封面加载**：播放列表条目浏览时复用已缓存的视频缩略图，而无需重新生成封面图。
- **仅保留相关的队列操作**：音频选择保留“下一首播放”和“加入队列”，在不支持这些操作的视频选择菜单中不再错误展示。

### 📦 安装
- **Obtainium 支持**：在项目 README 中添加了直接跳转 Obtainium 的徽章和配置链接，更方便地进行安装与更新追踪。

### ⚡ 媒体库、文档与稳定性
- **超大媒体库顺畅滑动**：包含数百个视频的列表在快速滑屏时会暂停缩略图解码、磁盘读取和缓存键运算，待滑动稳定后再恢复可视区域的批量加载。
- **增量播放进度保存**：5 秒一次的播放状态持久化仅更新受影响的列表行，而无需重新构建和重新排序所有视频，保持列表项稳定并减少滑行卡顿。
- **降低单卡片开销**：缩略图偏好设置每个屏幕仅监听一次，底层数据仓库操作移出主线程，超大视频选择器采用稳定内容类型与感知滚动的按需加载。
- **文档崩溃修复**：修复了 Issue #571 中浏览 mpv 输入命令文档时因重复的 `COMMAND:playlist-next` 列表键导致的崩溃。播放列表命令现在仅出现一次，且所有文档行均具备分类限定的唯一键。
- **更可靠的播放器状态**：修复了播放状态更新可能滞后于用户操作的问题，并改进了高频切歌期间队列、通知栏和播放列表的同步机制。

## 2.4.0 — 播放列表、播放可靠性与表现力导航

### 🎬 播放、画中画与性能
- **更快的视频启动速度**：从启动路径中移除了阻塞性的外部资源同步。校验过的内部 mpv 资源即刻复用，外部资源在播放开始后后台刷新。
- **可靠的跳转预览缩略图**：加固了类似 ThumbFast 的预览初始化、请求排队、缓存与解码机制，使拖动进度条时准确展示最新请求帧，杜绝过期帧替入。
- **彻底的画中画退出清理**：将画中画关闭处理统一为幂等销毁路径，杜绝退出画中画窗口后的播放残留、音频重复与轻微声音爆音。
- **更安全的播放过渡**：改进了频繁媒体切换场景下 yt-dlp、环境光模式、片段编辑器、渲染器、队列与音频播放器的生命周期处理。
- **更具参考价值的播放器诊断**：扩充了统计信息第 6 页，展示真实进程内存占用、Java/Native 堆内存、mpv 缓存大小、缓冲时长、数据包/文件缓存、种子状态及播放健康度数据。

### 📚 播放列表、队列与网络媒体
- **YouTube 播放列表导入**：支持从“播放列表”标签页导入 YouTube 及其他支持的网络播放列表链接，按顺序载入视频、标题、频道元数据与封面，与现有 M3U/M3U8 格式完全兼容。
- **富元数据播放队列**：将 YouTube 播放列表粘贴到链接栏后，会自动开始播放首个视频，并将所有项连同标题、频道、封面、时长和稳定 URL 元数据预载入播放器侧边抽屉中。
- **更灵活的播放队列**：新增“下一首播放”与“添加到队列”功能，支持音视频混合播放列表，具备可靠的本地 M3U 路径解析，并在媒体交接过程中提供更安全的队列归属管理。
- **共享收藏夹列表**：视频收藏现以“收藏的视频”呈现在主播放列表标签页中，而“收藏的歌曲”集合可在音乐与播放列表两处同时访问，封面大小设置保持统一。
- **更清爽的播放列表浏览**：收藏合集按媒体类型清晰归类，远程卡片具备统一的选中样式，网络播放列表缩略图与文件夹队列已恢复正常。
- **清晰的 yt-dlp 引导**：首次进行网络播放前会弹出提示确认安装 yt-dlp 并显示安装进度，不再表现为无限加载缓冲。

### 🔎 搜索、歌词与内容探索
- **生产级设置搜索**：全面扩大设置项搜索覆盖，支持加权模糊匹配、容错拼写匹配、子序列匹配、直接定位到条件设置项、精准滚动定位以及关键字高亮。
- **更全面的歌词覆盖**：新增 MP3 文件内嵌 ID3v2 歌词提取，并优化了 YouTube 媒体的在线歌词匹配查找。
- **专注的浏览器操作**：队列选择操作现仅在适用的模式下出现，避免在视频模式下展示依赖音频包含项的操作。

### 🧭 导航与界面交互

## 1.3.2

### 基于 hdr-toys 的专业 HDR 管线
- 彻底废弃旧有的简易 3 模式系统，换用由 [hdr-toys](https://github.com/natural-harmonia-gropius/hdr-toys) 驱动的高性能着色器 HDR 管线。
- 提供四种标准 HDR 模式：**BT.2100 PQ** (HDR10)、**BT.2100 HLG**、**BT.2020** 与 **Linear HDR**（mpv 原生，无额外着色器）。
- 内置 77 个 GLSL 运算着色器，初次使用时自动拷贝就位，零手动门槛。
- HDR 面板不再包含冗余的“Off”项；Off 作为默认状态通过 HDR 主按钮直接切换，面板仅展示激活的 4 种工作模式。
- 当环境不支持 GPU Next + Vulkan 时点击选择会给出清晰错误胶囊提示，并安全回退至关闭状态。
- 新增 `boostSdrToHdr` 增强偏好（专供 Linear HDR 链路调用）。
- 切换至 Off 或管线未就绪时，`HdrToysManager` 会干净释放所有着色器，杜绝跨会话着色器内存泄露。

### 电池续航与发热温控调优
- 加入 `ThermalMonitor` — 播放期间每 10 秒主动采样系统散热余量 (Android 11+)。
- 根据机身发热状态动态限制环境光着色器的采样开销：8 次采样（严重发热）、12 次（中度发热）、18 次（轻度温热）、全开无限制（凉爽）。
- 当系统温控余量跌破 40% 时，主动将 Anime4K 档位下调至 C/Fast，在掉帧发生前抢先抑制发热。
- 当环境光配置与上次编译版本完全一致时跳过重复编译 —— 消除横竖屏旋转与无效回调带来的 GPU 瞬间顿挫。
- 移除重复的播放位置轮询：不再同时采用事件监听与循环轮询写入同一个 StateFlow，根除了进度条无意义的二次重复重绘。
- 当控件隐藏时，后台播放进度轮询间隔从 250ms 延长至 500ms，闲置 JNI 唤醒降低 50%。

### 统计信息第 6 页优化
- **GPU 估算负载条校正**：此前采用累积掉帧与延迟统计，导致长时间播放后读数无限漂移至 100%，且受固定帧率基线干扰（120fps 零掉帧显示 70% 负载）。现改为依据当前帧率计算每秒丢帧增量 —— 0 丢帧即为 0%，全部丢失显示 100%。
- **修正 CPU 标签含义**：由模糊的“CPU Usage”改标为“应用 CPU (当前进程)”，准确体现其仅计量 MpvRx 自身消耗而非全局设备负荷。
- **丢帧数据展示每秒增量**：与累计丢帧并列展示当前每秒增量，瞬间渲染负荷一目了然。
- **暂停避让降频**：暂停播放时，统计数据轮询间隔由 1 秒放宽至 2 秒，静态画面下不再无谓空耗 JNI 调用。

### 手势与操作浮层独立开关
- 在播放器设置中开辟“手势与操作浮层”专区，提供 7 个独立的开关控制：
  - **音量滑块浮层** — 滑动调节音量时展现的纵向指示胶囊
  - **亮度滑块浮层** — 滑动调节亮度时展现的纵向指示胶囊
  - **长按倍速浮层** — 长按触发倍速时展现的指示标与滑轨
  - **画幅切换提示** — 切换画面宽高比时弹出的小气泡
  - **缩放级别提示** — 双指捏合画面缩放时的倍数提示
  - **循环与随机提示** — 切换单曲循环/列表随机时的状态提示
  - **按钮动作提示胶囊** — 自定义按钮、环境光开关、字幕拖拽及 Lua/JS 脚本派发的简短反馈文字
- 所有浮层默认**开启**，保持原有体验不变。
- 关闭浮层仅隐藏弹出的视觉指示气泡 —— 底层实际手势动作（调节音量、调整倍速等）依然正常生效。
